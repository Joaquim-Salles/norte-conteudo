# Carrosséis

Usar para explicar dores, processos, diferenças entre gestão e operação e aplicações dos produtos.

Estrutura recomendada: **gancho reconhecível → problema → consequência → caminho → solução NTB → CTA**.

Antes de criar uma pauta nova, conferir se ela conversa com pelo menos uma dor real do público: estoque pouco confiável, controles paralelos, pedidos desencontrados, perda de rastreabilidade, falta de visão da operação ou dificuldade de padronização.
